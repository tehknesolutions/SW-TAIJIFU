# M080 — Contra-ataque cooperativo

## Estrutura
`estímulo → defesa → recuperar estrutura → resposta em alvo → saída/guarda`.

## Drills V1
- jab técnico → parry → direto em manopla;
- jab → slip → jab em alvo;
- direto → saída lateral → direto em manopla;
- 1–2 lento → cobertura/recuo → jab na reentrada.

## Método
O atacante também segura/apresenta alvo quando apropriado, para que a resposta não precise atingir seu corpo. 5 repetições por sequência e troca de papéis.

## Progressão
Ataque anunciado → timing variável → escolha entre duas entradas conhecidas.

## Critério
A vontade de responder não deve fazer o praticante abandonar a defesa. A sequência só progride se ambos conseguem interrompê-la sob comando.
