# M048 — Chute lateral

## Mecânica V1
1. partir de posição estável;
2. transferir peso para a perna de apoio;
3. elevar o joelho em câmara confortável;
4. orientar quadril e pé de apoio sem torcer o joelho;
5. estender lateralmente de forma controlada;
6. retrair para a câmara;
7. recolocar o pé e recuperar guarda.

## Progressão
- câmara com apoio leve em parede/barra estável, apenas para equilíbrio;
- 5 extensões lentas por lado;
- depois executar sem apoio em amplitude reduzida.

## Critérios
- perna de apoio não fica travada;
- tronco inclina apenas o necessário;
- retração é tão controlada quanto a extensão;
- altura não compromete o eixo.

Não usar superfícies rígidas como alvo.
