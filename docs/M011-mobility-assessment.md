# M011 — Avaliação de mobilidade

A avaliação V1 observa, sem finalidade diagnóstica:

- elevação dos braços acima da cabeça;
- rotação dos ombros;
- flexão e extensão controlada de quadril;
- agachamento sem carga até amplitude confortável;
- dorsiflexão de tornozelo;
- rotação torácica;
- mobilidade suave de pescoço.

## Registro
Para cada item:
- confortável;
- limitado;
- desconfortável;
- não realizado.

Registrar também assimetrias percebidas entre lados.
