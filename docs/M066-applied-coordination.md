# M066 — Coordenação aplicada

## Drills V1
### A — mão + passo
Avanço + jab; recuo + guarda; lateral + jab. 5 ciclos por direção.

### B — alternância
Jab esquerdo/direito conforme a base adotada, seguido de elevação alternada de joelhos. 30 s.

### C — cruzado corporal
Marcha cruzada por 20 s → assumir guarda → 20 s de 1–2 lento.

### D — direção + técnica
Frente = jab; trás = guarda; esquerda = passo lateral; direita = pivot. Executar comandos mentalmente por 45 s.

## Progressão
Precisão → ritmo → fluidez → velocidade moderada.

## Critérios
- lados não são confundidos repetidamente;
- guarda retorna sem comando consciente a cada técnica;
- pés e mãos cooperam sem travar a respiração;
- aumentar velocidade não altera a ordem correta.
