# M062 — Defesa + contra-ataque

## Biblioteca V1
- parry → direto;
- slip externo → direto;
- slip interno técnico → jab e saída;
- cobertura lateral → jab–direto;
- recuo → avanço + jab;
- passo diagonal → direto;
- check técnico imaginário → reposição → jab.

## Estrutura pedagógica
Cada sequência possui três fases claramente reconhecíveis:
1. defesa;
2. reposicionamento/recuperação;
3. resposta.

## Drill
Selecionar três sequências. Executar 5 repetições lentas de cada e depois 3 × 30 s de shadowboxing restrito às três escolhidas.

## Critério
A resposta nunca apaga a defesa. Se antecipar o contra-ataque faz o praticante abandonar guarda ou equilíbrio, reduzir velocidade e reconstruir a sequência.
