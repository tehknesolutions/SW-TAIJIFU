# M009 — Modelo de registro de treino

Cada sessão deve registrar, no mínimo:

- data;
- duração;
- objetivo da sessão;
- exercícios e técnicas praticadas;
- séries, repetições, rounds ou tempo;
- intensidade percebida de 1 a 10;
- estado de energia antes e depois;
- dor ou desconforto relevante;
- observações técnicas;
- progresso percebido;
- evidência opcional: vídeo, foto, cronômetro ou contagem.

## Regra
O registro deve ser simples o bastante para ser usado em toda sessão e detalhado o bastante para permitir comparação longitudinal.
