# M081 — Fluxo ataque-defesa

## Objetivo
Treinar continuidade sem transformar cada troca em competição.

## Fluxo V1
A inicia uma ação permitida → B defende/reposiciona → pausa curta → B inicia → A responde. O papel ofensivo alterna naturalmente após cada ciclo.

## Repertório inicial
Somente jab, direto, passos, cobertura, parry, slips pequenos e saídas de linha. Técnicas adicionais entram separadamente após domínio.

## Round
3 × 60 s, intensidade 2–4/10.

## Regras
- não pontuar nem procurar vencedor;
- não acelerar para surpreender;
- uma ou duas ações antes de reiniciar;
- distância deve permitir controle;
- qualquer perda de controle reinicia o drill em ritmo menor.

## Métrica
Avaliar leitura, distância, equilíbrio, guarda e capacidade de alternar iniciativa sem congelar.
