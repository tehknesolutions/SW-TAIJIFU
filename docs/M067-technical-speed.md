# M067 — Velocidade técnica

## Princípio
Velocidade é uma camada adicionada sobre uma técnica existente, não um substituto para mecânica.

## Escada V1
Executar a mesma sequência em quatro faixas subjetivas:
- 25% — precisão;
- 40% — fluidez;
- 55% — velocidade moderada;
- 70% — somente quando trajetória, base e guarda permanecem estáveis.

Percentuais representam percepção de velocidade, não medição laboratorial.

## Drill
Escolher jab–direto. Fazer 5 repetições em cada faixa, descansando brevemente e comparando qualidade.

## Gate
Subir de faixa apenas se:
- trajetória permanece limpa;
- corpo não fica rígido;
- respiração continua;
- guarda retorna;
- equilíbrio permanece.

Se qualquer item degrada, retornar à faixa anterior.
