# M061 — Contra-ataque fundamental

## Conceito
Contra-atacar não significa responder imediatamente a qualquer custo. A ordem V1 é:

`perceber → defender/sair → recuperar estrutura → responder → recuperar guarda`.

## Respostas simples de shadowboxing
- slip imaginário → jab;
- parry imaginário → direto;
- recuo → jab na reentrada;
- passo lateral → jab;
- cobertura → 1–2 técnico.

## Drill
5 repetições lentas de cada padrão. Depois 2 × 30 s escolhendo apenas uma defesa e uma resposta por vez.

## Critérios
- defesa continua existindo mesmo sabendo que haverá resposta;
- contra-ataque não exige perda de base;
- potência não é objetivo;
- guarda é recuperada ao final.
