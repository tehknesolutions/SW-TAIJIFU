# M003 — Definição formal do SimpleWay Taijifu

SimpleWay Taijifu é a plataforma pedagógica do Taijifu.

Cada habilidade percorre a cadeia:

CONHECER → VER → EXECUTAR → REPETIR → INTEGRAR → AVALIAR → DOMINAR

A plataforma deve suportar treino individual, currículo digital, acompanhamento de progresso e futura assistência por IA.
