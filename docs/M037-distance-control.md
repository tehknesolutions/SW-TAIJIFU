# M037 — Controle fundamental de distância

## Zonas V1
- **fora** — técnicas de mão não alcançam sem deslocamento;
- **entrada** — um pequeno passo cria alcance;
- **alcance** — técnica pode chegar com estrutura, sem inclinação excessiva;
- **curta** — espaço reduzido; golpes longos deixam de ser adequados.

## Drill individual
Usar um ponto visual imaginário à frente. Aproximar e afastar com passos curtos, identificando mentalmente cada zona.

## Regra de alcance
Não buscar distância esticando excessivamente tronco ou ombro. Se a técnica exige perder a base para chegar, a distância está errada.

## Critério
O praticante ajusta posição com os pés antes de compensar alcance com postura ruim.
