# M013 — Avaliação de coordenação

## Testes V1
1. Alternância mão direita / mão esquerda em ritmo constante.
2. Marcha cruzada: mão direita no joelho esquerdo e vice-versa.
3. Sequência simples de passos: frente → trás → esquerda → direita.
4. Guarda + avanço + retorno.
5. Jab alternado mantendo base e guarda.

## Avaliação
Observar:
- sequência correta;
- ritmo;
- dissociação entre membros;
- retorno à posição inicial;
- necessidade de parar para reorganizar o movimento.
