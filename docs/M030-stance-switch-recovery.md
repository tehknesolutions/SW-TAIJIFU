# M030 — Troca e recuperação de base

## Princípio
Trocar a base não significa saltar ou cruzar descontroladamente os pés. A prioridade é terminar funcional.

## Progressão V1
1. partir da guarda;
2. reduzir momentaneamente a distância entre os apoios sem unir os pés;
3. reposicionar os pés de forma controlada;
4. recuperar largura e orientação da base;
5. confirmar guarda, visão e equilíbrio.

## Drill
5 trocas lentas → pausa → checagem de postura. Realizar para ambos os lados.

## Critério
Após cada troca, o praticante deve conseguir parar imediatamente ou iniciar um deslocamento sem passo corretivo extra.

Velocidade só aumenta quando a recuperação deixa de exigir reorganização consciente.
