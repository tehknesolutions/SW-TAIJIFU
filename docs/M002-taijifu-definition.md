# M002 — Definição formal do Taijifu

Taijifu é um sistema marcial em construção que integra preparação física, mobilidade, bases, movimentação, striking, defesa, curta distância, clinch, grappling fundamental, condicionamento e aplicação progressiva.

Técnicas só entram no cânone quando formalmente aprovadas. O sistema não presume que toda técnica de uma modalidade externa pertença automaticamente ao Taijifu.
