# M050 — Integração mãos + pernas

## Objetivo
Conectar golpes de mão e chutes sem transformar a combinação em uma sequência desconectada de movimentos.

## Combinações V1
- jab → chute frontal;
- jab → direto → chute frontal;
- jab → direto → low kick técnico;
- jab → chute circular;
- direto → gancho → chute circular.

## Método
Executar primeiro em shadowboxing, com baixa velocidade e amplitude confortável. A transição entre mãos e pernas deve preservar guarda, base e distância.

## Drill
5 repetições lentas de cada combinação. Depois 3 × 30 s escolhendo livremente apenas combinações já dominadas.

## Critérios
- não cruzar os pés para alcançar;
- chute parte de uma base recuperável;
- mãos retornam à proteção;
- após o chute, o praticante termina pronto para mover novamente;
- qualidade técnica precede quantidade.
